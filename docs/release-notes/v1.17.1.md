# v1.17.1

`v1.17.1` is a compatibility-preserving patch for mobile calendar workflows,
personal calendar feed clarity, and link-based onboarding feedback.

## Highlights

- Multi-day unavailability is shown as one clear date and time range in the
  mobile agenda.
- All entry status filters remain visible on narrow screens without horizontal
  scrolling.
- The mobile calendar presents one contextual action for creating care entries
  instead of overlapping or duplicate controls.
- Personal calendar feed titles include the assigned child labels, making
  subscriptions easier to distinguish in calendar clients.
- A completed owner or invitation flow shows a one-time confirmation after the
  browser returns to the app.

## Compatibility

- No database migration is added by this patch.
- Existing application data, sessions, memberships, invitations, recurring
  rules, calendar feed URLs, and feed tokens remain compatible.
- Feed scope and authorization remain unchanged; only event titles gain child
  labels.
- Deployment environment variables are unchanged from v1.17.0.

## Validation

The release is validated with lint, unit and integration tests, production
build, browser tests on desktop, iPhone, and iPad profiles, runtime security
tests, strict release checks, container validation, CodeQL, and release
artifact checksum verification.
