# v1.24.3

`v1.24.3` makes event names in personal calendar feeds concise and consistent.

## Personal calendar events

- Events for one child use the form `Child at Care party`.
- Events for multiple children list their names before the responsible care
  party.
- The same event-title rules apply to overall and care-party-specific feeds.
- Calendar names remain separate from individual event summaries.

## Privacy and compatibility

Event summaries are derived from domain records. They do not include account
display names, email addresses, OIDC subjects, or other authentication
identifiers. Historical records with a deleted child or care party use neutral
fallback labels.

No database migration or API change is required. Existing application data,
memberships, invitations, backups, portable transfers, and feed URLs remain
compatible.

The Helm chart is updated to `0.5.3` with application version `1.24.3`.

## Validation

The release is validated with unit and integration tests, responsive browser
checks, runtime security tests, container and Helm smoke tests, dependency
auditing, CodeQL, and strict release checks. Published artifacts are promoted
to the `testing` channel for separate runtime acceptance before the release
package is closed.
