# v1.11.0

`v1.11.0` adds the foundation for self-hosted onboarding and app-managed access
without changing the existing production promotion channels.

## Added

- Admin-only instance readiness information for abstract version, runtime,
  migration, setup, and feature status checks.
- Public setup-state metadata in `/api/session` so the UI can identify fresh
  installations without relying on browser-local state.
- Application-managed memberships that can override OIDC or trusted-proxy
  group-derived roles for known users.
- Explicit first-run owner bootstrap for fresh installations. The signed-in
  setup user confirms ownership once, receives an admin membership, and setup
  completion is written to settings and audit log.

## Security

- OIDC group mapping remains the compatibility fallback when no app membership
  exists.
- Native OIDC provisional setup sessions are only allowed while first-run setup
  is incomplete. Ordinary write APIs still require an app role with write
  permissions.
- Owner bootstrap is unavailable after setup completion, preventing silent
  later takeover through the setup flow.
