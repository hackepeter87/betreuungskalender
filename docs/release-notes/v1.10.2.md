# v1.10.2 - Mobile layout regression fixes

## Summary

`v1.10.2` is a patch release for mobile layout regressions found during
demo validation after `v1.10.1`.

The release does not include secrets, real user data, databases, backups,
exports, or deployment-specific values.

## Fixes

- Mobile agenda cards for external calendar events now use a stable one-column
  layout. Long calendar names no longer collapse into a narrow vertical text
  column.
- Mobile contact-rule time-span fields now stay inside their card. Offset and
  time inputs no longer extend beyond the form container.
- Mobile contact-rule summary metrics and generated-entry actions now use stable
  responsive rows. The seventh metric and help buttons no longer appear detached
  from their cards.
- Mobile holiday statistics and care-party share rows now stay inside their
  panels. The fifth metric spans the full row and person shares are rendered as
  readable cards instead of loose text.
- Mobile analytics export actions now use full-width rows so CSV/PDF buttons and
  help icons no longer overlap on narrow screens.
- Mobile care-entry forms now use compact period fields, toggles, and help
  buttons so the form no longer feels oversized on narrow screens.
- Mobile care-entry collapsible sections now keep trip, cost, and notes headers
  aligned inside their cards.
- Mobile calendar-feed settings now group status, scope selection, help icon, and
  explanatory copy with consistent spacing.
- Mobile entry status filters now wrap into a compact grid so every option is
  visible without horizontal scrolling.
- Notification settings now hide the E-Mail channel until server-side E-Mail
  delivery is implemented, avoiding disabled placeholder controls in the UI.
