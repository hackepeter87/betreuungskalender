# v1.20.7

`v1.20.7` stabilizes first-use caregiver selection, deployed member lists, and
the application shell across desktop and mobile layouts.

## Changes

- The established PWA icon is now used consistently in the desktop sidebar,
  collapsed navigation, and mobile header.
- Desktop sidebar footer controls now keep Settings, navigation collapse, and
  the signed-in account in a stable order.
- Instance information and invitation creation use balanced responsive grids.
- The additional first-use caregiver can be selected as primary without first
  entering a custom label. New appointments still default to the signed-in
  user's caregiver.
- The exact technical local-development identity is no longer exposed as a
  deployed workspace member or assignment candidate.

## Compatibility

Migration `029_local_development_identity_cleanup` revokes deployed access and
active delivery credentials only for the exact technical development identity.
Its user record remains available for historical audit references. Local mode,
existing domain data, real workspace members, sessions, invitations, and feed
tokens remain compatible.

The Helm chart is updated to `0.1.7` with application version `1.20.7`.

## Validation

The release is validated with linting, unit and integration tests, browser
tests, the production build, runtime security tests, container and Helm
validation, dependency auditing, and strict release checks.
