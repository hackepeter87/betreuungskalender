# v1.35.4

`v1.35.4` improves interoperability of personal calendar subscriptions in the
supported self-hosted application.

## Calendar subscriptions

- Personal iCalendar feeds now advertise an hourly refresh interval using the
  standard calendar refresh properties understood by compatible clients.
- The application documentation explains that the calendar client controls
  the actual update schedule and how operators can distinguish client fetches
  from scheduling or connectivity problems.

## Maintenance

- Compatible static-delivery and development-tool dependencies are updated.
- Newly reported transitive dependency advisories are resolved without
  weakening the existing audit and release gates.

Existing feed URLs, event identifiers, visible event content, access controls,
and revocation behavior remain unchanged. No database migration or breaking
API, authentication, authorization, backup, or transfer contract change is
included. Existing SQLite and PostgreSQL installations remain compatible.

The Helm chart is `0.16.4` with application version `1.35.4`. The release is
published first to `testing`. Promotion to `production` or `latest` requires a
separate explicit approval.
