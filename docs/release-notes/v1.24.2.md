# v1.24.2

`v1.24.2` makes multi-day records consistent in the responsive calendar
agenda.

## Calendar agenda

- Multi-day care and unavailability records appear on every occupied day.
- Timed and all-day external-calendar records follow the same day coverage.
- Start, intermediate, and final days receive clear day-specific labels.
- Every repeated card retains the complete date and time range.
- Daily record counts include the records that are visible on that day.

## Date and time behavior

- An end at midnight does not occupy the following day.
- Imported all-day calendar records retain their exclusive end-date behavior.
- The agenda remains limited to the selected calendar month.

## Compatibility

No database migration or API change is required. Existing application data,
memberships, invitations, backups, portable transfers, and calendar sources
remain compatible.

The Helm chart is updated to `0.5.2` with application version `1.24.2`.

## Validation

The release is validated with unit and integration tests, responsive browser
checks, runtime security tests, container and Helm smoke tests, dependency
auditing, CodeQL, and strict release checks. Published artifacts are promoted
to the `testing` channel for separate runtime acceptance before the release
package is closed.
