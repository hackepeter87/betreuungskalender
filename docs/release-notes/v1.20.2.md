# v1.20.2

`v1.20.2` is a maintenance release for the `v1.20` application and Helm
deployment line.

## Changes

- Updated the reproducible build and continuous-integration toolchain to
  Node.js 24.18.0 LTS with npm 12.0.1.
- Added an explicit dependency install-script policy for the native SQLite
  module and the frontend build tool while keeping optional scripts disabled.
- Reduced the production container to a digest-pinned minimal Node.js runtime
  without a shell, package manager, or build-only operating-system tools.
- Updated Compose health checks and maintenance guidance to invoke the runtime
  directly with Node.js.

## Compatibility

No database migration or application configuration change is required.
Existing Compose, direct-container, and Helm deployments remain compatible.
The production container continues to run as a non-root user with the existing
data and backup mount paths.

## Validation

The release is validated with linting, unit and integration tests, the
production build, runtime security tests, container and Helm validation,
browser tests, dependency auditing, and strict release checks.
