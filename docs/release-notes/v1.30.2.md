# v1.30.2

`v1.30.2` is a dependency compatibility release for the self-hosted
application. It updates supported runtime and build dependencies without
changing domain behavior, configuration, APIs, or the persistence schema.

## Maintenance updates

- The mail transport and request rate-limiting dependencies move to their
  supported releases while retaining the existing validation and failure
  behavior.
- SQLite and shared persistence dependencies are updated with the established
  SQLite and PostgreSQL compatibility checks.
- The container build uses the refreshed supported Node.js 24 image baseline.
- The frontend build moves to Vite 8, the current React plugin, and native
  Rolldown code splitting. The explicit ES2022 target, lazy page boundaries,
  PDF isolation, service-worker behavior, and existing CSS rendering remain
  unchanged.

## Validation

- Unit, documentation, runtime-security, browser, accessibility, visual,
  dependency review, CodeQL, Trivy, Helm, update, and rollback checks remain
  enforced.
- SQLite and PostgreSQL 16 and 18 container paths verify startup, persistence,
  transfer behavior, restart, and database outage handling.
- The resolved production npm dependency tree reports no known vulnerabilities
  at release preparation time.

## Compatibility

The Helm chart is `0.11.2` with application version `1.30.2`. This release has
no database migration and no intentional API or configuration compatibility
break. SQLite remains the default persistence backend; PostgreSQL 16 through 18
remains optional with its database-specific backup and restore procedure.

The release is published first to `testing`. Promotion to `production` or
`latest` requires a separate explicit approval.
