# v1.10.1 - UI layout hardening

## Summary

`v1.10.1` is a patch release for layout defects found after `v1.10.0`.
It should be used for testing before any `production` or `latest` promotion.

The release does not include secrets, real user data, databases, backups,
exports, or deployment-specific values.

## Fixes

- Mobile calendar agenda now filters holiday periods to the selected month.
  A July agenda no longer shows March or April holiday blocks.
- Mobile month calendar cells render a bounded number of events and use short,
  readable labels such as `Ferien`, `Beide`, and `Dienst`.
- Mobile entries, analytics, holiday management, backup, audit log,
  unavailability, external calendar, and feed settings views were hardened
  against horizontal overflow and misaligned help buttons.
- Desktop Settings default-value fields and help icons are aligned in a stable
  responsive grid.

## Verification

- `npm run lint`
- `npm run build`
- Focused iPhone Playwright regression tests
- Focused desktop Playwright regression tests
- Visual screenshots for mobile calendar agenda/month, entries, analytics,
  holidays, backup, audit log, unavailability, desktop settings, and desktop
  calendar

## Upgrade notes

- No database migration is included.
- No authentication, API, or data-model behavior changes are included.
- Keep `latest` production-only. Promote this release to `testing` first and
  verify the demo environment before any production promotion.
