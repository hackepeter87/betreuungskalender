# v1.12.0

`v1.12.0` adds owner-managed invitations and member administration for shared
instances. It builds on the app-managed membership model from `v1.11.0` and
keeps OIDC/trusted-proxy groups as compatibility fallback.

## Added

- Invitation token acceptance for users joining an existing instance.
- Owner/admin member-management APIs for app users, explicit app roles,
  invitations, and app-role removal.
- Settings UI for creating invitations, copying the one-time invitation code,
  assigning member roles, removing explicit app roles, and revoking open
  invitations.
- Optional provider-neutral SMTP delivery for invitation emails. Manual code
  sharing remains available even when mail delivery is disabled or fails.

## Security

- Invitation tokens are stored hashed and are only shown once after creation.
- Invitations expire, are single-use, and can be revoked by an owner/admin.
- Member-management and invitation endpoints require an app-managed owner/admin
  role.
- Invitation email delivery uses generic error responses and avoids logging
  tokens or SMTP secrets.

## Operations

- Configure `INVITATION_PUBLIC_BASE_URL` so generated invitation links point to
  the externally reachable instance URL.
- Enable SMTP delivery with `INVITATION_EMAIL_ENABLED=true` and the `SMTP_*`
  environment variables. Keep mail disabled when SMTP is not configured.
- Existing OIDC group mapping remains a fallback for known deployments, but
  explicit app memberships are the intended shared-instance access model.
