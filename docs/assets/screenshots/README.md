# Documentation screenshots

This directory contains screenshots made exclusively with fictional
demonstration data.

Before replacing or adding an image, follow the privacy checklist in
[`docs/screenshots.md`](../../screenshots.md). Do not add real names, addresses,
notes, evidence references, private domains, authentication details, or
calendar data from a private case.

Maintained images, both referenced from the root README:

- `dashboard-desktop.png`: 1440 × 900 desktop dashboard.
- `calendar-mobile.png`: 390 × 844 mobile calendar agenda.

These are unmodified copies of the reviewed Linux visual-regression references.
The source paths, fixed fixture, capture settings and reproduction steps are in
the screenshot guide above. No separate screenshot generator is maintained.
