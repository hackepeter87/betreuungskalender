# v1.18.2

`v1.18.2` is a maintenance release that refreshes the server, static asset,
PDF sanitation, and build dependency chain.

## Highlights

- Fastify and its static asset integration use their current maintained
  compatible versions.
- Transitive runtime and build packages are resolved to current compatible
  patch versions.
- GitHub Actions installs the npm version declared by the project before
  dependency installation and validation.
- Release tests verify that Node-based workflows keep this npm version pin.

## Existing data and compatibility

- No database migration is added by this release.
- Existing care data, recurring rules, holidays, memberships, sessions,
  invitations, notification subscriptions, and calendar feed tokens remain
  compatible.
- Public API routes, request formats, and response formats are unchanged.

## Configuration

- Deployment environment variables are unchanged from v1.18.1.
- Update release references to `1.18.2` and keep the existing data and backup
  mounts writable by the container user.

## Validation

The release is validated with the dependency audit, lint, unit and integration
tests, production build, browser tests, runtime security tests, strict release
checks, container validation, CodeQL, and release artifact checksum
verification.
