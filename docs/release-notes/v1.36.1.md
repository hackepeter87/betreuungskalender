# v1.36.1

`v1.36.1` corrects mobile layout regressions found while validating v1.36.0
without changing application behavior or stored data.

## Mobile layout

- Page actions, native date and month fields, help controls, notification
  headings, and recurring-care controls remain inside their owning sections at
  narrow viewport widths.
- Calendar-feed status separates its compact state label from the explanatory
  text so long messages reflow normally.
- Reports and audit entries use readable single-column metadata on phones.
- Summary groups with an odd number of values use a deliberate final
  label/value row instead of leaving an empty metric cell.
- The application shell reserves space for the fixed mobile navigation once,
  keeping final sections and actions consistently reachable.

## Validation

- Chromium and WebKit layout contracts cover 320 and 390 CSS pixels.
- Reviewed visual baselines cover the affected mobile, tablet, and desktop
  surfaces in light and dark presentation.
- Accessibility, runtime-security, PostgreSQL, container, Helm, dependency,
  and vulnerability gates remain unchanged.

## Upgrade notes

No database migration, product-logic change, or breaking API,
authentication, authorization, backup, transfer, or calendar-feed change is
included. Existing SQLite and PostgreSQL installations remain compatible.

The Helm chart is `0.17.1` with application version `1.36.1`. The release is
published first to `testing`. Promotion to `production` or `latest` requires a
separate explicit approval.
