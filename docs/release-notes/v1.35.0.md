# v1.35.0

`v1.35.0` makes member access easier to understand and keeps the same access
rules consistent throughout a self-hosted installation.

## Explicit member access

- Owners can see what each fixed role is allowed to view or change before
  inviting a member or updating existing access.
- Care-data access can cover all children, selected children, or no care
  records.
- Invitation and member administration use the same access model and present a
  summary before a change is confirmed.

## Consistent enforcement

- The server applies role capabilities and care-data scopes to care entries,
  reports, calendar feeds, confirmations, transfers, and related records.
- Empty or restricted scopes do not expose unrelated care data through direct
  API requests.
- Access changes are revalidated when applied and recorded through the existing
  audit history.

## Compatibility

- SQLite and PostgreSQL use equivalent migration and authorization behavior.
- Migration `037` stores explicit member data scopes while preserving existing
  workspace memberships.
- Existing backups, restores, invitations, and portable transfer packages
  remain supported.

The Helm chart is `0.16.0` with application version `1.35.0`. The release is
published first to `testing`. Promotion to `production` or `latest` requires a
separate explicit approval.
