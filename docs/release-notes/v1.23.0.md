# v1.23.0

`v1.23.0` consolidates the responsive application layout so core views follow
the same width, spacing, typography, panel, and form rules.

## Changes

- Use a fluid desktop content area for the dashboard, calendar, settings,
  report, backup, and documentation views.
- Give the dashboard calendar the full available width and place secondary
  information below it in an even responsive grid.
- Apply shared page, section, panel, field, action, and typography tokens
  instead of page-specific spacing baselines.
- Align settings sections and responsive form grids across wide desktop,
  tablet, and mobile viewports.
- Keep the collapsed sidebar account menu within the viewport while returning
  the released sidebar width to the main content.
- Use a transparent navigation variant of the existing application logo while
  retaining the established PWA and favicon assets.
- Replace generic documentation-rule cards with concise, practical guidance
  sections.

## Compatibility

This release changes presentation only. It does not add a database migration or
change API contracts, authentication, transfer packages, backups, feed tokens,
or domain data. Report pages remain fluid on screen and keep their dedicated
print layout.

The Helm chart is updated to `0.4.0` with application version `1.23.0`.

## Validation

The release is validated with linting, unit and integration tests, browser
layout checks on desktop, tablet, and mobile viewports, the production build,
runtime security tests, container and Helm smoke tests, dependency auditing,
and strict release checks.
