# v1.20.5

`v1.20.5` aligns initial ownership and first-use setup across the supported
authentication modes.

## Changes

- Native OIDC ordinary login requires an active application membership.
- The first native-OIDC owner is established through the one-time owner setup
  link before guided first-use setup begins.
- Existing installations without an owner can use the same owner link without
  recreating or changing children, care parties, rules, entries, or settings.
- Trusted-proxy first-use setup requires the configured admin group.
- The obsolete owner-bootstrap API and Settings action have been removed.

## Compatibility

No database migration or new configuration value is required. Existing owners,
active memberships, invitations, feed tokens, and domain data remain
compatible. Integrations using `POST /api/setup/owner-bootstrap` must use the
documented owner-link and first-use flow instead.

The Helm chart is updated to `0.1.5` with application version `1.20.5`.

## Validation

The release is validated with linting, unit and integration tests, browser
tests, the production build, runtime security tests, container and Helm
validation, dependency auditing, and strict release checks.
