# v1.18.1

`v1.18.1` adds unobtrusive, standards-based guidance for installing the
Betreuungskalender as a Progressive Web App.

## Highlights

- Supported Chromium-based browsers show an install action only after the
  browser reports that installation is available. The action opens the native
  browser installation prompt.
- iPhone and iPad users receive concise guidance for adding the application to
  the Home Screen through Safari.
- The guidance can be dismissed and remains hidden for 30 days on the current
  device.
- No suggestion is shown when the application already runs in standalone
  mode, or while owner setup or invitation onboarding is active.

## Existing data and compatibility

- No database migration is added by this release.
- Existing care data, recurring rules, holidays, memberships, sessions,
  invitations, notification subscriptions, and calendar feed tokens remain
  compatible.
- Public API routes, request formats, and response formats are unchanged.

## Configuration

- Deployment environment variables are unchanged from v1.18.0.
- Update release references to `1.18.1` and keep the existing data and backup
  mounts writable by the container user.

## Validation

The release is validated with lint, unit and integration tests, production
build, browser tests on desktop, iPhone, and iPad profiles, runtime security
tests, strict release checks, container validation, CodeQL, and release
artifact checksum verification.
