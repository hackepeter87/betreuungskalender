# v1.13.0

`v1.13.0` improves the first-use experience for fresh self-hosted
installations. It adds a guided setup flow, clearer empty states, initial
calendar/feed discovery, and a local preference for inline help icons.

## Added

- Guided first-use setup wizard for fresh installations. The flow covers owner
  confirmation, child setup, care-party setup, default values, and initial
  calendar/feed guidance.
- Setup-focused care-party defaults so new instances can start with a primary
  care party and standard handover values.
- Clearer empty states for missing child, care-entry, care-party, and calendar
  feed data.
- Calendar/feed discovery guidance for external calendar imports, holiday
  source selection, and personal calendar feeds.
- Local Settings preference to show or hide inline field-help icons.

## Changed

- The navigation entry formerly labeled "Rules" is now labeled "Help".
- Central Help content remains available even when inline field-help icons are
  hidden.
- First-use guidance is presented as a connected setup flow instead of separate
  configuration hints.
