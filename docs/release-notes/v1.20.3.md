# v1.20.3

`v1.20.3` is a dependency-maintenance release for the `v1.20` application
and Helm deployment line.

## Changes

- Updated compatible Fastify runtime packages.
- Updated the native OIDC client and mail delivery runtime dependencies.
- Refreshed transitive runtime packages while retaining the existing minimal,
  digest-pinned Node.js container runtime.

## Compatibility

No database migration or application configuration change is required.
Existing Compose, direct-container, and Helm deployments remain compatible.

## Validation

The release is validated with linting, unit and integration tests, browser
tests, the production build, runtime security tests, container and Helm
validation, dependency auditing, and strict release checks.
