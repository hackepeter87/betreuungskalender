# v1.20.6

`v1.20.6` keeps native-OIDC owner setup and invitation onboarding aligned with
the authenticated application shell.

## Changes

- The exact owner-setup and invitation entry routes now reach their existing
  one-time-token validation handlers before the application login fallback.
- Ordinary browser pages, protected APIs, and unknown onboarding subpaths keep
  their existing authentication requirements.
- Normal OIDC login still requires an active application membership.
- Production-runtime coverage now validates the complete owner and invitation
  flows with the built frontend fallback present.

## Compatibility

No database migration or new configuration value is required. Existing owners,
memberships, invitations, sessions, feed tokens, and domain data remain
compatible.

The Helm chart is updated to `0.1.6` with application version `1.20.6`.

## Validation

The release is validated with linting, unit and integration tests, browser
tests, the production build, runtime security tests, container and Helm
validation, dependency auditing, and strict release checks.
