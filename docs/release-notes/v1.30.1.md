# v1.30.1

`v1.30.1` is a maintenance release for the self-hosted application. It updates
supported application and development dependencies, refreshes pinned delivery
inputs, and strengthens release validation without changing domain behavior or
the persistence schema.

## Maintenance updates

- Fastify, OpenID Connect, React, Zod, browser-test tooling, type declarations,
  PostCSS, and related maintained tools receive supported patch or minor
  updates.
- The minimal Node.js 24 runtime image and reviewed GitHub Actions use updated
  immutable references. Node.js 26, Vite 8, TypeScript 7, and other major
  toolchain changes remain outside this release.
- Local worktree checkouts are excluded from linting and repository analysis,
  avoiding duplicate analysis without excluding tracked source files.

## Validation

- The application contract, runtime-security suite, visual browser matrix,
  dependency review, CodeQL, Trivy, Helm chart, and release invariants remain
  enforced.
- SQLite and PostgreSQL container workflows verify startup, transfer dry run,
  import, restart persistence, database outage behavior, invalid secrets, and
  privacy-preserving logs.
- The resolved npm dependency tree reports no known vulnerabilities at release
  preparation time.

## Compatibility

The Helm chart is `0.11.1` with application version `1.30.1`. This release has
no database migration and no intentional API or configuration compatibility
break. SQLite remains the default persistence backend; PostgreSQL 16 through 18
remains an optional backend with its database-specific backup and restore
procedure.

The release is published first to `testing`. Promotion to `production` or
`latest` requires a separate explicit approval.
