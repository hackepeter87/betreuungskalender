# v1.5.1 - Post-release UI polish and CI hardening

## Summary

`v1.5.1` is a patch release for the `v1.5.0` contact-rule and calendar-sharing
line. It keeps the functional surface unchanged and focuses on UI polish,
release hygiene, and a date-stable runtime-security test.

## Changes

- Normalized the Settings page layout on mobile and desktop so external
  calendar source rows, toggle controls, and calendar feed fields use consistent
  spacing and no longer overflow narrow viewports.
- Aligned the mobile dashboard close-month action with its help control.
- Tightened repository hygiene checks around generated image artifacts.
- Made native OIDC runtime-security session fixtures expire relative to the
  test run instead of a fixed calendar date.

## Upgrade notes

- No database migration is added in this release.
- No environment variable changes are required.
- No production promotion is performed by publishing this release. The `latest`
  tag remains production-only and moves only with the production promotion
  workflow.

## Validation

Before publication, validate:

- `npm run lint`
- `npm run test`
- `npm run test:security-runtime`
- `npm run build`
- `npm run release:check`
- Browser smoke test for the mobile dashboard header and Settings page layout.
- Runtime verification after update with the expected `v1.5.1` version.
