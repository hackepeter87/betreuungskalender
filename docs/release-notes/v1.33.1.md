# v1.33.1

`v1.33.1` is a focused dependency and runtime security maintenance release.

## Security and reliability

- The PDF sanitization dependency is updated to its patched maintenance
  release.
- The digest-pinned distroless Node.js runtime includes refreshed distribution
  packages and continues to run as a non-root user.
- The final application image is revalidated with dependency, runtime-security,
  container, SQLite, PostgreSQL 16 and PostgreSQL 18 checks.

## Compatibility

- Application behavior, public APIs, authentication, and configuration remain
  unchanged.
- No database migration is required.
- Existing SQLite and PostgreSQL installations, backups, and portable transfer
  packages remain compatible.

The Helm chart is `0.14.1` with application version `1.33.1`. The release is
published first to `testing`. Promotion to `production` or `latest` requires a
separate explicit approval.
