# v1.35.3 pre-release acceptance

Date: 2026-10-25

## Scope

This acceptance reviewed the combined v1.35.3 maintenance baseline before
versioning and artifact publication. It covers compatible dependency updates,
the supported Node.js 24 runtime baseline, accessibility checks, and the pinned
GitHub Actions update. It does not approve a published image or chart; those
checks remain part of the separate release and testing-channel acceptance.

Only fictional test data and isolated test databases were used.
