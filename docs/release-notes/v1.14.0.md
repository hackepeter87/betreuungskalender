# v1.14.0

`v1.14.0` completes the self-hosted onboarding documentation pass after the
first-use setup, memberships, invitations, and optional invitation email
delivery work from the previous releases.

## Changed

- Invitation emails now use the configured setup installation label as the
  sender display name when available.
- `SMTP_FROM` remains the sender mailbox and keeps the existing fallback
  behavior when no installation label is configured.
- The sender display name is normalized before it is used in the mail header.

## Documentation

- Added a self-hosted onboarding and member-administration guide covering
  first-use setup, owner bootstrap, app memberships, invitations, and readiness
  checks.
- Updated the README to reflect the current release line, native OIDC mode,
  trusted-proxy compatibility, setup state, app memberships, invitations, and
  instance readiness.
- Linked setup and member-administration guidance from installation and
  security documentation.
- Updated the security policy supported-version wording for the current release
  line.

- `npm run build`
