# v1.35.3

`v1.35.3` is a maintenance release for the supported self-hosted application.
It updates reviewed dependencies and runtime pins, strengthens bounded legacy
migration validation, and keeps automated accessibility and security checks
current.

## Security and runtime maintenance

- Supported web server, validation, and mail transport dependencies include
  their current compatible security and maintenance fixes.
- Legacy migration payloads are constrained by the established processing
  limits before records are normalized or imported.
- The build uses the refreshed pinned Node.js `24.22.1` baseline with npm
  `12.2.1`; the minimal non-root runtime image remains unchanged in structure.

## Compatibility and quality

- Compatible application, build, lint, and browser-test dependencies are
  updated after SQLite, PostgreSQL, container, and end-to-end validation.
- Accessibility checks use the current compatible rules, and visible labels
  are included in the accessible names of affected navigation and calendar
  controls.
- GitHub Actions continue to use immutable revisions, including the refreshed
  CodeQL SARIF upload action.

No database migration or breaking API, authentication, authorization, backup,
or transfer contract change is included. Existing SQLite and PostgreSQL
installations remain compatible. Deferred major runtime and compiler upgrades
are not part of this release.

The Helm chart is `0.16.3` with application version `1.35.3`. The release is
published first to `testing`. Promotion to `production` or `latest` requires a
separate explicit approval.
