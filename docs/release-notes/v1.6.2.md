# v1.6.2 - Calendar feed location and child-color regression coverage

## Summary

`v1.6.2` is a small patch release for calendar-feed completeness and UI
regression coverage.

## Changes

- Personal iCalendar feeds now include each care entry's location as
  `LOCATION`.
- Custom entry locations are exported first; otherwise the feed uses the
  configured location label.
- Calendar feeds still exclude notes, evidence references, trips, and costs.
- A Playwright regression test now changes a child color in Settings and proves
  the selected color is rendered in the calendar.

## Upgrade notes

- No database migration is required.
- No environment variable changes are required.
- No API or authentication behavior changes are included.
- Publishing this release does not update `latest`; `latest` remains
  production-only and moves only with the production promotion workflow.

## Validation

- `npm run lint`
- `npm run test`
- `npm run test:e2e`
- `npm run build`
- `npm run release:check`
