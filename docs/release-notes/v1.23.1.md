# v1.23.1

`v1.23.1` corrects responsive dashboard and settings layouts following the
shared application baseline introduced in v1.23.0.

## Changes

- Keep dashboard confirmation, child summary, data quality, and backup panels
  proportionate instead of stretching short notices to the height of adjacent
  content.
- Arrange dashboard secondary information in balanced responsive groups below
  the full-width calendar.
- Keep compact settings fields in bounded columns on wide screens while the
  surrounding sections continue to use the available desktop width.
- Stack external-calendar import controls inside their panel on tablet and
  mobile viewports.

## Compatibility

This release changes presentation only. It does not add a database migration or
change API contracts, authentication, transfer packages, backups, feed tokens,
or domain data.

The Helm chart is updated to `0.4.1` with application version `1.23.1`.

## Validation

The patch is validated with linting, unit and integration tests, browser layout
checks on desktop, tablet, and mobile viewports, the production build, runtime
security tests, container and Helm smoke tests, dependency auditing, and strict
release checks.
