# v1.20.1

`v1.20.1` is a maintenance release for the `v1.20` application and Helm
deployment line.

## Changes

- Updated affected transitive dependencies to maintained patch versions.
- Stabilized recurring-rule and selected-month browser coverage so validation
  remains deterministic across calendar months.
- Updated the bundled Helm chart application and chart versions for this patch
  release.

## Compatibility

No database migration or application configuration change is required.
Existing Compose, direct-container, and Helm deployments remain compatible.

## Validation

The release is validated with linting, unit and integration tests, the
production build, runtime security tests, container and Helm validation,
browser tests, dependency auditing, and strict release checks.
