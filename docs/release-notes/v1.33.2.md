# v1.33.2

`v1.33.2` is a compatible dependency maintenance release for the supported
Node.js 24 baseline.

## Maintenance updates

- The PostgreSQL client, mail transport, and static asset delivery dependencies
  are updated within their existing major versions.
- Compatible development tools for linting, local orchestration, stylesheet
  processing, TypeScript execution, and frontend builds are refreshed.
- The dependency security gate is restored so high-severity production
  dependency findings continue to block automated quality checks.

## Compatibility

- Application behavior, public APIs, authentication, and configuration remain
  unchanged.
- No database migration or operator action is required.
- Existing SQLite and PostgreSQL installations, backups, and portable transfer
  packages remain compatible.

The Helm chart is `0.14.2` with application version `1.33.2`. The release is
published first to `testing`. Promotion to `production` or `latest` requires a
separate explicit approval.
