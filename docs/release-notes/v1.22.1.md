# v1.22.1

`v1.22.1` makes portable instance transfers easier to review before domain data
is replaced.

## Changes

- Compare the current installation, the selected transfer package, and the
  expected post-import record counts by localized domain category.
- Show package metadata, omitted runtime data, historical actor mappings, and
  named checksum, format, schema, reference, foreign-key, and integrity checks.
- Highlight populated categories that would be replaced without imported
  records.
- Require a separate confirmation dialog with the same aggregate replacement
  counts before the transactional import starts.
- Show an immediate completion summary and a direct path to historical actor
  mapping after import.
- Offer a browser-generated review report containing only versions, aggregate
  counts, check outcomes, warning counts, and a shortened fingerprint.

## Privacy and compatibility

Dry runs still do not change SQLite, files, settings, or the audit log. Detailed
review results remain in the current browser state and are not retained as an
import-history log. The optional review report excludes names, email addresses,
domain records, complete identifiers, URLs, claims, tokens, and the short-lived
dry-run receipt.

Existing v1.22.0 transfer packages and legacy application JSON exports remain
supported. A real import still revalidates the complete package and fingerprint
before replacing domain data atomically.

The Helm chart is updated to `0.3.1` with application version `1.22.1`.

## Validation

The release is validated with linting, unit and integration tests, browser
tests, the production build, runtime security tests, container and Helm smoke
tests, dependency auditing, and strict release checks.
