# v1.20.4

`v1.20.4` completes the first-use setup and OIDC invitation flow for the
`v1.20` application and Helm deployment line.

## Changes

- Reworked the setup wizard into compact, responsive sections and retained
  support for adding multiple children during initial setup.
- Manual sharing and email delivery now use the same complete, expiring
  invitation link.
- Removed the obsolete invitation-code entry form and API route.
- Regular OIDC sign-in now requires an active workspace membership after the
  first owner has completed setup.
- Versioned Helm charts are published as OCI artifacts from the validated
  release tag.

## Compatibility

No database migration or new configuration value is required. Existing active
memberships and invitations remain valid. Applications that integrated the
obsolete invitation-code API must switch to the documented `/invite?token=...`
browser flow.

## Validation

The release is validated with linting, unit and integration tests, browser
tests, the production build, runtime security tests, container and Helm
validation, dependency auditing, and strict release checks.
