# v1.36.2

`v1.36.2` corrects the recurring-care planning hierarchy and calendar preview
without changing stored rules or generated event identities.

## Recurring-care planning

- The page context now describes the task as care planning instead of using the
  unclear target-versus-actual comparison label.
- A new series initially previews the period beginning with its first
  appointment and ending at the supported synchronization horizon.
- Deliberately selected preview dates remain unchanged. When they do not
  overlap the series, the page explains the mismatch and offers an explicit
  action to align the preview.
- Editor and preview columns size to their own content, avoiding a stretched
  empty preview panel and stacking naturally when space is limited.

## Validation

- Unit coverage verifies bounded, open-ended, one-off and temporarily
  incomplete preview ranges.
- Browser coverage verifies a future series, manual preview selection and
  explicit realignment.
- Responsive and accessibility checks cover phone, tablet and desktop widths,
  keyboard operation, accessible names, focus visibility and reflow.

## Upgrade notes

No database migration, recurrence-rule change or breaking API,
authentication, authorization, backup, transfer, calendar-feed or event-UID
change is included. Existing SQLite and PostgreSQL installations remain
compatible.

The Helm chart is `0.17.2` with application version `1.36.2`. The release is
published first to `testing`. Promotion to `production` or `latest` requires a
separate explicit approval.
