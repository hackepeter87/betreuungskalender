# v1.35.2

`v1.35.2` packages reviewed compiler, dependency, workflow, and container
maintenance on the supported Node.js 24 baseline. It does not change product
behavior or begin the separately planned Node.js 26 LTS migration.

## Runtime and configuration

- TypeScript 6 is used as the transition compiler for the existing source and
  contract checks.
- Optional local environment files are loaded explicitly by application and
  operational entry points.
- Compatible Fastify, mail, browser-test, lint, build, and supporting package
  updates are included after repository and runtime validation.

## Automation and containers

- GitHub Actions references use reviewed immutable revisions and the workflow
  contract tests verify the approved setup sequence.
- Container builds use the refreshed immutable Node.js 24 base-image digest.
- The distroless runtime image remains unchanged.

## Compatibility

- No API, database schema, authentication, authorization, backup, transfer, or
  user-interface changes are included.
- Existing SQLite and PostgreSQL installations remain compatible.
- Node.js 26 remains deferred until its release line is officially LTS and the
  dedicated runtime migration has passed its own acceptance gates.

The Helm chart is `0.16.2` with application version `1.35.2`. The release is
published first to `testing`. Promotion to `production` or `latest` requires a
separate explicit approval.
