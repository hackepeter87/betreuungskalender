# v1.6.1 - Unavailability modal layout fix

## Summary

`v1.6.1` fixes the unavailability form layout that could overlap labels, help
buttons, date/time inputs, and impact toggles in the modal.

## Changes

- The unavailability form now opens in a dedicated wider modal layout.
- Start and end date/time inputs are grouped into stable cards with one help
  button per logical group.
- Impact toggles are rendered as explicit option cards with separate switch,
  label, and help-button columns.
- The modal remains vertically scrollable and prevents horizontal overflow on
  desktop, tablet, and mobile viewports.

## Upgrade notes

- No database migration is required.
- No environment variable changes are required.
- No API or authentication behavior changes are included.
- Publishing this release does not update `latest`; `latest` remains
  production-only and moves only with the production promotion workflow.

## Validation

- `npm run lint`
- `npm run test`
- `npm run test:e2e`
- `npm run build`
- `npm run release:check`
- Browser visual checks for the unavailability modal on desktop, tablet, and
  mobile.
