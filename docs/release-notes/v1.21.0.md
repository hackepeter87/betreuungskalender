# v1.21.0

`v1.21.0` extends the guided first-use setup so an installation can begin with
no child, one child, or several children without leaving the setup flow.

## Changes

- The child step now uses repeatable cards with name or abbreviation, birth
  month, birth year, and calendar color.
- Child cards can be added and removed on desktop, tablet, and mobile layouts.
- The first-use API accepts an optional `children` array with up to 20 records.
- The previous singular `child` input remains accepted for one compatibility
  release. Sending both forms is rejected as ambiguous.
- The owner, care parties, settings, and all initial children are stored in one
  SQLite transaction. An invalid record leaves the complete setup unchanged.

## Compatibility

No database migration or new configuration variable is required. Existing
installations, active memberships, invitations, sessions, domain data, and
deployment methods remain compatible.

The Helm chart is updated to `0.2.0` with application version `1.21.0`.

## Validation

The release is validated with linting, unit and integration tests, browser
tests on desktop, iPhone, and iPad, the production build, runtime security
tests, container and Helm validation, dependency auditing, and strict release
checks.
